# A2UI

This repository contains the A2UI project code and associated applications.

## Recent Updates

- **Video Player Component**: Added a new video player component with support for YouTube video integration.
- **Fitness App**: Created a new dedicated application interface for fitness (`fitness.html`).

## Repository Structure

- `S14Code/`: Contains the main application, routing, and UI clients.
- `glc_v3/`: Contains the voice and backend service components.
